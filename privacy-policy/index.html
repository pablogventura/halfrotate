HalfRotate — Privacy Policy

Last updated: 2026-06-05

HalfRotate is an open-source Android app that filters system auto-rotation to orientations you choose (portrait, landscape, or custom presets).

Data collection

HalfRotate does not collect, store, transmit, or sell any personal data. The app works entirely on your device and does not connect to any analytics, advertising, or tracking services.

Permissions

  • Modify system settings — used only to read and adjust screen rotation settings.
  • Foreground service — keeps the rotation filter active while you have enabled it; shown via a notification you can dismiss by disabling the filter.
  • Notifications — required on Android 13+ to display the active filter notification.
  • Boot completed — optionally restarts the filter after reboot if you had it enabled.
  • Battery optimization exemption — optional; requested to improve reliability on some devices (e.g. Xiaomi/MIUI).

Open source

Source code is available under GPL-3.0-or-later at github.com/pablogventura/halfrotate.

Contact

Report issues via GitHub Issues.

Changes

Material changes to this policy will be reflected in the app repository and tagged releases.
